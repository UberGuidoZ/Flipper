# LPD433 & PMR446 Sound Player

This project contains files designed to play the sound indicated in each file's title, using compatible hardware and software.

## Overview

The project includes sound files associated with two radio frequency bands: LPD433 and PMR446.

Each file is identified by its title, which indicates the sound it is intended to reproduce. Depending on the file and the compatible device, the sound may be associated with a specific channel or frequency.

## How to Use

1. Browse the available files.
2. Identify the sound you want to reproduce by reading the file's title.
3. Open or load the selected file using compatible hardware or software.
4. Activate the appropriate playback function.

The sound reproduced depends on the selected file and the implementation of the compatible device or application.

## Important Notes

- File titles identify the sounds associated with each file.
- A file's name alone does not guarantee compatibility with every device.
- Playing an audio file is different from transmitting a radio-frequency signal.
- Actual RF transmission, where supported, depends on the hardware, firmware, and application.
